# 日本の農業用自動操舵技術 動向調査レポート（2024-2026年）

---

## 1. 日本市場の概要

### 1.1 農業機械市場全体

日本の農業機械市場は2024年に約108億米ドル（約1兆6,200億円）と評価され、2033年には約135億米ドルに達すると予測されている（CAGR 2.5%）。スマート農業技術の採用、政府による機械化推進のインセンティブ、持続可能な専門機械への需要増加が成長を牽引している。

### 1.2 スマート農業市場規模

矢野経済研究所の調査によると、2024年度のスマート農業の国内市場規模（事業者売上高ベース）は前年度比109.9%の**331億5,400万円**の見込みである。2030年度には**788億4,300万円**まで拡大すると予測されている。

### 1.3 自動操舵システムの普及状況

北海道農政部技術普及課の調査によると、自動操舵装置の全国出荷台数は着実に増加しており、**令和6年度（2024年度）は全国で7,490台**が出荷された（前年度比+約1,400台）。平成20年度以降の**累計出荷台数は38,760台**に達している。

- 北海道向け出荷台数：3,380台（前年度比+500台）、累計23,110台（全国の約6割）
- GNSSガイダンスシステムの全国出荷台数：3,940台、累計37,650台

### 1.4 スマート農業の普及率

- 農林水産省の2023年調査：データ活用農業を行う経営体は24万2,300経営体（普及率26.1%）
- 個人経営体：24.5%、団体経営体：60.7%
- 日本政策金融公庫調査：スマート農業「導入済み」は全体で**44.9%**
  - 畑作：68.7%、稲作（北海道）：55.4%、稲作（都府県）：49.2%

## 2. 主要メーカーの動向

### 2.1 クボタ（株式会社クボタ）

クボタは日本のスマート農業のリーダーとして、トラクタ・田植機・コンバインの主要3機種すべてで無人自動運転仕様を実現している。

**アグリロボシリーズ**
- **アグリロボトラクタ MR1000A**：RTK-GNSSユニット、サラウンドビュー、人・障害物検知システムを搭載。圃場外周を一周するだけで最適な作業ルートを自動作成し、耕うん・代かき・肥料散布・播種等を自動運転で実施。
- **アグリロボコンバイン DRH1200A**：2024年1月発売。世界初の無人自動運転コンバイン。AIカメラによる人検知、ミリ波レーダーによる車両検出を搭載。価格は2,203万7,400円〜。約4年間・数百万件の画像データでAIを学習。
- 2024年までにアグリロボシリーズの累計出荷台数は**約700台**。

**自動運転ロードマップ**
- Step 1（実現済み）：有人での自動操舵
- Step 2（製品化済み）：有人監視下での無人自動運転（通信距離約250m以内）
- Step 3（研究開発中）：遠隔監視による完全無人化、圃場間移動の自動化

**2025年の注目トピック**
- **大阪万博2025**にて世界初の「自動運転水素燃料電池トラクタ」を公開。100馬力クラス、1回の水素充填で最大12時間稼働、排出物は水蒸気のみ。トヨタMIRAIの燃料電池技術をベースに開発。
- **Type: V（世界初公開）/ Type: S 汎用プラットフォームロボット**：車体の高さ・幅を変形可能で、作物の間隔や成長状況に合わせて自動調整。1台で耕うん・中間管理・防除・収穫まで対応。Type: SはCES 2025でBest of Innovation Prize受賞。
- NVIDIAとの戦略的パートナーシップ（2020年〜）、NTTグループ・東京大学との共同研究によりStep 3の実現を加速。

**遠隔監視の実証実験**
2022年度から、監視センターから37km離れた北海道大学農場と7km離れた岩見沢西谷内農場の合計4台のロボット農機を遠隔制御・監視する「リモート農業」実証を実施。

### 2.2 ヤンマー（ヤンマーアグリ株式会社）

ヤンマーは自動運転技術搭載農機シリーズを**「スマートパイロット（SMARTPILOT）」**と総称し、幅広いラインナップを展開している。

**2024年3月発売：ロボット/オートトラクター YT4R/5Rシリーズ**
- ロボットトラクター：近距離監視での無人自動作業（レベル2）
- オートトラクター：直進作業・旋回の自動化
- 価格帯：13,409,000円〜17,193,000円（税込）
- 新機能：コンバインとのデータ共有、タッチパネル式カラーモニター、AUTOボタン追加

**2024年11月発売：直進アシストトラクター YT4Aシリーズ**
- 型式：YT460A/465A/472A
- 価格帯：9,446,800円〜11,014,300円（税込）
- D-GNSS方式の自動操舵システム、基準線のA・B点登録による平行作業
- YTトラクター全シリーズに「直進アシスト仕様」がラインアップ完了

**技術仕様**
- RTK-GNSS方式採用：精度±2〜3cm
- 0.2km/hからの低速作業対応
- 1人2台の有人-無人協調作業が可能
- タブレット1つで作業コントロール

### 2.3 井関農機（ISEKI）

**2024年5月発売：ロボットトラクタ TJW1233-R（123馬力）**
- 国内最大クラスの有人監視型ロボットトラクタ
- 自動化レベル2、変形ほ場対応
- RTK補正・VRS補正・IMU補正による高精度自動運転
- Home位置誘導機能：作業終了後に設定位置まで自動走行
- 価格帯：2,191万9,700円〜2,302万6,300円（税込）

**自動操舵技術「ISEKI DREAM PILOT」**
- GNSS活用のICTソリューション
- 有人トラクタと無人ロボットトラクタの2台同時作業対応

**その他の展開**
- 2025年度上期：コンバインに直進アシスト仕様（Z型）を追加
- 自動抑草ロボット「アイガモロボ」：IGAM2を発売、除草作業回数58%削減を確認

### 2.4 三菱マヒンドラ農機

日本第4位の農業機械メーカー（2024年時点の生産高ベース）。

**自動操舵システム SE-Navi**
- 農業情報設計社との共同開発による後付け型GNSS自動操舵システム
- メーカー希望小売価格：**60万480円（税込）〜**
- 従来製品の1/3〜1/2の意欲的な価格設定
- 直進自動操舵に特化したシンプル設計
- トラクター・田植機に後付け可能

**スマートアイドライブ**
- GPS付きトラクタとして、価格を抑えた自動操舵対応モデル

**2024年の新製品**
- 2024年11月：新型コンパクトトラクター「XS18/XS20/XS23/XS25」をフルモデルチェンジ発売

## 3. 政府施策

### 3.1 スマート農業技術活用促進法（2024年10月施行）

2024年6月14日に「農業の生産性の向上のためのスマート農業技術の活用の促進に関する法律」が成立し、2024年10月1日に施行された。

**背景**：今後20年間で基幹的農業従事者が現在の約1/4（111万人→30万人）にまで減少する見込み。

**主な支援内容**
- 「生産方式革新実施計画」の国認定を受けた農家への支援
- 日本政策金融公庫による長期・低利融資（償還期限25年以内、利率0.65%〜1.75%）
- 税制特例（特別償却、登録免許税の軽減）
- 農研機構の試験圃場・ロボットトラクター等の供用
- 種苗法特例（出願料・登録料3/4減免）
- ドローンによる農薬散布の航空法許可・承認手続のワンストップ化

**対象技術**：自動収穫機、ロボットトラクター、運搬ロボット、直播ドローン、環境制御システム、スマート選果システム等

### 3.2 スマート農業実証プロジェクト

令和元年度から開始し、全国**217地区**で実証を実施（令和元年度69地区、令和2年度55地区、令和2年度補正24地区、令和3年度34地区、令和4年度23地区、令和5年度12地区）。

**主な成果**
- ロボットトラクターによる耕うんで倍の効率、準備時間全体で約7割の労働時間削減
- AI予測と収穫データの組み合わせで半日かかっていた作業が30分に短縮
- 化学農薬・化学肥料の使用低減を確認
- スマート農機のシェアリングによる導入コスト低減

### 3.3 農業機械の自動走行に関する安全性確保ガイドライン

平成29年（2017年）3月に策定。段階的に改正が行われている。

- **令和5年（2023年）改正**：ロボットコンバインを対象に追加
- **令和6年（2024年）3月改正**：遠隔監視によるロボット農機（トラクター、茶園管理機械）を追加。3部構成に再編（第1部：目視監視、第2部：遠隔監視、第3部：機種別追加事項）
- **令和6年度**：ほ場間移動を含む遠隔監視ロボット農機のガイドライン策定を検討中

### 3.4 補助金・助成金制度

**スマート農業・農業支援サービス事業導入総合サポート緊急対策事業**
- 2025年度は前年度の10億円規模から**100億円規模**に拡充（10倍）

**強い農業づくり総合支援交付金（農業支援サービス事業支援タイプ）**
- 補助率：1/2、限度額：1,500万円
- 農業機械のレンタル・サブスクリプション提供等への支援

**中山間地域等直接支払交付金**
- スマート農業による省力化・効率化への支援：上限年間200万円、10aあたり5,000円

**その他の活用可能な制度**
- ものづくり補助金、IT導入補助金、経営強化税制、投資促進税制等の併用可能

## 4. 技術動向

### 4.1 みちびき（QZSS）を活用した高精度測位

**CLAS（Centimeter Level Augmentation Service）**
- QZSSが提供する無料の高精度測位補強サービス
- PPP-RTK方式を採用し、地上の電子基準点網（GEONET）データから誤差情報を衛星経由で配信
- GPS単独の約10m精度を**1m〜数cm**に飛躍的に向上
- **最大のメリット**：基地局不要、インターネット接続不要、補正情報無料

**7機体制への移行（2025年目標）**
- 2022年時点：4機体制 → 2023〜2024年に追加3機打ち上げ → 2025年に7機体制運用開始
- 7機体制でみちびき単独での高精度測位が可能に

**ALLYNAV AF305のCLAS対応テスト結果**（2025年）
- 初回測位時間（TTFF）：平均20分以内にFix解獲得
- 繰り返し走行誤差：**±2.5cm未満（rms）**
- 方位角安定性：±0.5度以内
- 直線走行最大誤差：**1.5cm未満**
- 他社CLASモジュール比で平均誤差約30%低減、水平精度5.1cm

### 4.2 RTK測位サービスの普及

**ソフトバンク ichimill（イチミル）**
- 独自設置の**3,300カ所以上の基準点**を活用（国土地理院の約1,300カ所の2.5倍）
- 測位精度：数センチメートル
- 料金：年間36,000円（税抜）、月額換算約3,000円
- 基準点設置不要で農業現場での採用が拡大

**その他のRTKサービス**
- FJD Ntrip（岩佐商会）：年間利用料18,480円（税込）
- 従来月額数万円だったネットワークRTKが月数千円程度に低価格化

### 4.3 自動運転レベルの体系

農林水産省による農機の自動運転レベル区分：

| レベル | 内容 | 状況 |
|--------|------|------|
| レベル1 | 有人搭乗での自動操舵（直進アシスト、フル自動操舵） | 製品化済み |
| レベル2 | 有人監視下での無人自動運転（目視監視距離内） | 製品化済み |
| レベル3 | 遠隔監視での無人自動運転（農機自体がAIで周囲監視・安全操作） | 実証段階 |

### 4.4 後付け自動操舵システムの進展

ロボットトラクター（1,000万円超）に比べ、後付け自動操舵システム（**約60万〜132万円**）は導入障壁が大幅に低い。

**主要製品一覧（2025年時点で14製品以上が市販）**
- **ALLYNAV AF305**：RTK精度±25mm、最大35km/h対応、CLAS対応、マゼックスとの戦略的パートナーシップ（2025年6月）
- **トプコン ValueLine**（2024年11月発売）：110万円（7インチ）〜132万円（10インチ）、Wi-Fiアダプター標準装備、複数農機で使い回し可能
- **三菱マヒンドラ SE-Navi**：60万480円〜、直進自動操舵特化
- **FJD AT2**：後付け型、ichimill等と組み合わせ可能

### 4.5 圃場間移動の自動化

圃場間の農道走行を含む完全自動化はレベル3に相当し、現在研究開発・実証段階にある。2024年3月のガイドライン改正で遠隔監視ロボット農機の安全性確保策が追加され、令和6年度にはほ場間移動を含むガイドライン策定の検討が進められている。クボタは北海道での遠隔監視実証（37km離れた農場からの制御）を実施済み。

## 5. 課題と展望

### 5.1 中山間地での導入課題

- 日本の農地の約4割を占める中山間地域は、傾斜地・変形ほ場・小区画が多く、大型ロボット農機の導入が困難
- 通信環境（携帯電話・インターネット）の未整備地域が存在し、RTK測位やクラウド連携に支障
- 農業従事者の高齢化が平地以上に深刻で、デジタル技術への抵抗感
- 2025〜2030年の5年間で農用地8万4,000haの減少を防止する目標が設定

### 5.2 高齢化・担い手不足との関連

- 2024年の農業従事者：**111.4万人**（うち65歳以上が79.9万人＝**71.7%**）
- 基幹的農業従事者の平均年齢：**68.4歳**（2022年）
- 今後20年で農業従事者は**約1/4（30万人）**に減少見込み
- 農業経営体数は2013年の151万4,100から2024年の88万3,300に減少（10年で63万体減）
- スマート農業は人手不足の解決策として期待されるが、IT技術への不安が普及の障壁に

### 5.3 コスト面の課題

- ロボットトラクター：1,000万〜2,300万円（大規模農家のみ導入可能）
- 後付け自動操舵システム：60万〜132万円（比較的導入しやすい）
- スマート農業導入の最大の課題は**「初期投資費用が高い」（79.0%）**、次いで「ランニングコストが高い」（34.7%）
- 稲作の大規模農家（20ha以上）は全体の約1.6%のみ
- 農業支援サービス（レンタル・サブスクリプション・作業代行）による導入コスト低減が注目
- CLAS対応機器の普及により、RTK基地局設置費用や通信費の削減が期待

### 5.4 今後の展望

- **2025年**：みちびき7機体制の運用開始により、CLAS測位精度の更なる向上と安定性確保
- **2030年まで**：スマート農業技術活用促進法に基づく集中的な技術導入期間
- レベル3（遠隔監視完全無人化）の商用化に向けた実証の加速
- 水素燃料電池トラクターの実用化に向けたフィールドトライアル開始
- 農業支援サービス事業の拡大（補助金100億円規模への拡充）
- 小型・中山間地向けスマート農機の開発推進
- 1台で複数作業を行う汎用プラットフォームロボット（クボタType: V/S）の実現
