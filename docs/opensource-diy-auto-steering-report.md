## 1. AgOpenGPS

### 1.1 プロジェクト概要

AgOpenGPS（AOG）は、カナダの農家でありソフトウェア開発者であるBrian Tischler氏が開発したオープンソースの精密農業プラットフォーム。GPS誘導による自動操舵、セクション制御、マッピング機能を、市販の電子部品とコミュニティ設計ハードウェアで実現する。

主な機能:
- **ABライン・ABカーブ・コンターガイダンス**: Pure Pursuit方式による操舵角出力
- **セクション制御**: 最大16セクション（異なる幅）または最大64セクション（同一幅）
- **自動枕地旋回（UTurn）**: カーブおよびABラインでの自動ヘッドランドターン
- **マッピング・境界管理**: 圃場境界の作成、面積計算

### 1.2 最新バージョン

最新安定版は**v6.8.2**。

**v6.8.0/v6.8.2の主な変更点:**
- 585ファイル変更、30,954行追加、17,559行削除の大規模アップデート
- **64ビット専用**に移行
- **トラックコピー機能**: フィールド間でのトラックのインポート・エクスポート
- **トラックからの境界構築**: AB・カーブトラックから圃場境界を自動生成
- **AgDiag診断ツール**: 新しいトラブルシューティングユーティリティ

次世代プロジェクト「**AgOpenNext**」がリポジトリ上で進行中。

## 2. その他のオープンソース自動操舵プロジェクト

### 2.1 RTKLIB

東京海洋大学の高須知二氏が開発したオープンソースGNSS測位ソフトウェア群。

- **対応衛星系**: GPS、GLONASS、Galileo、QZSS（みちびき）、BeiDou、SBAS
- **測位モード**: Single、DGPS、Kinematic、Static、Moving-Baseline、PPP等
- **ライセンス**: BSD 2-clause（商用利用可）
- **農業応用**: AgriBus-GMiniRのRTK測位演算に採用。gpssnaviプロジェクトではPythonベースのトラクターガイダンスを実装

### 2.2 FarmHack

DIY型自律走行トラクターのプロジェクト。現状は遠隔操作電動トラクターとして機能。次段階でRTK GPSガイダンス、その後コンピュータビジョン導入を計画。

### 2.3 ROS-Agriculture

ROSベースの農業ロボティクスエコシステム。lawn_tractor（自律走行芝刈りトラクター）等を提供。

### 2.4 FarmBot

100%オープンソースの精密農業ロボット。CNCガントリー型の小規模菜園向け。CADモデル、BOM、ソースコードが公開。

### 2.5 gpsnavi

日本人開発者によるRTKLIBを活用したPythonベースの農業トラクター用RTK-GPS/GNSSガイダンスシステム。

### 2.6 AgriBus-NAVI（日本発）

北海道帯広市の農業情報設計社が開発したAndroid用GPSガイダンスアプリ。

- **世界的普及**: 170万以上のインストール、140カ国以上で使用
- **精度**: 内蔵GPS=数メートル、外部GNSS=0.2〜0.3m、RTK=2〜3cm
- **RTK演算**: オープンソースのRTKLIBを活用

### 3.1 u-blox ZED-F9P

- **RTK精度**: 0.01m + 1ppm CEP（水平）

## 5. 商用製品との比較

### 5.1 コスト比較

| 項目 | DIY（AgOpenGPS） | 中価格帯商用（FJD等） | 高価格帯商用（Deere/Trimble） |
|---|---|---|---|
| **初期費用** | 約10〜60万円 | 約100〜200万円 | 約165〜450万円 |
| **年間サブスク** | 無料 | 0〜数万円 | 約15〜18万円/年 |
| **5年間総コスト** | 約10〜60万円 | 約100〜250万円 | 約240〜540万円 |

### 5.2 精度・信頼性の比較

| 項目 | DIY（AgOpenGPS） | 商用システム |
|---|---|---|
| **RTK精度** | ±2.5cm（ZED-F9P + RTK） | ±2.5cm |
| **信頼性** | ユーザーの技術力に依存 | ディーラーサポート・保証あり |
| **設定難易度** | 高（数週間〜数カ月のDIY期間） | 低（ディーラー設置） |
| **互換性** | 汎用（ほぼ全トラクターに対応） | メーカー依存 |

### 5.3 投資対効果

AgOpenGPS導入農家の事例: 年間10万ドルの肥料費用を初年度で**20%削減**。一般的にRTKシステム導入で肥料15〜30%削減、農薬10〜20%削減、燃料8〜15%削減が見込まれる。

## 6. オープンソース x ISOBUS

### 6.1 AgIsoStack++

Open-Agricultureプロジェクトが提供する完全無料のオープンソースISOBUSライブラリ。

- **言語**: C++11（STL使用）
- **機能**: VTクライアント、タスクコントローラークライアント、トランスポートレイヤー
- **スポンサー**: Raven Industries（Rust版AgIsoStack-rsの支援）
- **ESP32対応**: 内蔵TWAIインターフェースを利用、外部CANコントローラー不要
- **Arduino対応**: AgIsoStack-Arduinoとして軽量版を提供（Teensy対応）

### 6.2 M5IsobusVT

M5Stack Core2（ESP32 + PSRAM）上にISOBUSバーチャルターミナルを実装するプロジェクト。

### 6.3 Open ISOBUS File Server（Linux）

ISO 11783-13規格を部分的に実装。LinuxカーネルのCAN_J1939ソケットを利用。

### 6.4 ISOAgLib

大型農業機械のCAN通信に対応するオープンソースISOBUS実装。

### 6.5 ISOMAXデベロッパーキット

ホビイストや農家向けのISOBUSデベロッパーキット。大手農機メーカーの支援を受けている。

## まとめと展望

1. **コストの継続的低下**: ZED-F9Pに加え、Unicore UM980やQuectel LG290Pの登場でRTKハードウェアがさらに低価格化。完全なDIY自動操舵が**10万円以下**で構築可能に。

2. **コミュニティRTK基盤の成熟**: Centipede RTKが世界30カ国で展開。個別基地局設置の必要性が減少。

3. **ソフトウェアの進化**: AgOpenGPS v6.8.2で大規模リファクタリング、次世代「AgOpenNext」が進行中。

4. **ISOBUSのオープンソース化**: AgIsoStack++により、ESP32等の安価なマイコンでISOBUS通信が実装可能に。

5. **日本の課題と機会**: 言語障壁、農機メーカー独自規格が障壁だが、大阪府の自作支援事業や新潟GPSコンソーシアム等の取り組みが広がっている。
